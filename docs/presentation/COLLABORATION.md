# 3인 원격 AI 개발 협업 발표 자료

`story-guard-collaboration.html`은 16:9 슬라이드 16장, 약 10~12분 분량의 별도 발표 자료입니다. 기존 제품 소개 발표는 유지합니다.

## 내용

1. 세 사람, 하나의 제품
2. 병렬 개발을 막는 문제
3. 계약·독립 개발·통합 원칙
4. A/B/C 역할 분담
5. 모듈 연결과 계약의 위치
6. 먼저 합의할 최소 계약
7. 공통 가상 원고와 실패 사례
8. 가짜 구현을 사용하는 병렬 개발
9. 현재 저장소의 결합 지점
10. 사람과 AI의 공통 기준 문서
11. AI 작업 카드 예시
12. 계약 변경 절차
13. 매일 통합과 원격 작업 규칙
14. 자동 검사와 AI 비용 분리
15. 첫 1~2일의 시작 순서
16. 팀이 합의할 사항

기존 Story Guard 자료와 같은 크림·보라·청록 계열, Pretendard Variable과 Source Serif를 사용합니다. 글꼴·라이선스·도식·조사 근거를 HTML 하나에 포함합니다. 슬라이드 열람에는 인터넷이 필요하지 않으며 근거 링크는 외부 페이지로 연결됩니다.

## 조작

- 방향키 / Space / PageUp / PageDown: 이동
- Home / End: 첫 장 / 마지막 장
- 목차: 슬라이드 바로 이동
- 조사 근거: 출처·현재 코드·미확정 범위 확인
- F: 전체 화면, Escape: 대화상자 닫기
- 브라우저 인쇄: 슬라이드별 PDF 출력
- 모바일: 슬라이드별 세로 읽기 배치

## 수정과 재생성

원본 조사는 `docs/research/2026-09-09-remote-ai-collaboration.md`, 편집할 발표 템플릿은 `source/collaboration-slides.html`입니다.

```sh
python3 docs/presentation/source/build-collaboration.py
```

이 자료는 조사 기반 협업 제안이며 팀 배정·계약 구현·CI 설정 완료를 뜻하지 않습니다.

## 발표 자료 검증

- Chrome에서 오프라인으로 열고 글꼴 2개 로딩, 외부 요청 0건 확인.
- 16장 전체를 1440×900, 1920×1080, 390×844에서 검사. 콘텐츠의 슬라이드 경계 초과와 가로 넘침 없음.
- 목차·키보드 이동·조사 근거·전체 화면 동작 확인.
- 인쇄 PDF 16페이지와 페이지별 텍스트 확인.
- 화면 캡처·검사 결과·PDF: `output/playwright/collaboration/`.
