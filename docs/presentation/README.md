# Story Guard 발표 자료

`story-guard.html` 하나만 전달하면 됩니다. 이미지 7개, 글꼴 2개, 폰트 라이선스를 파일 안에 포함했으며 인터넷 연결 없이 브라우저에서 열 수 있습니다.

## 구성

- 16:9 슬라이드 20장, 약 12~15분 발표용.
- 문제와 사용자 경험, 디자인 시안, 자료·교정 구조, 분석 기술, 데스크톱 본제품과 웹 체험판의 역할, 실행 위치, 원고 전송, 비용 제한, 공개 전 검증과 일정.
- 시안 7개는 초기 웹 기획의 참고 이미지입니다. 데스크톱 시작 화면·앱 다운로드·체험 제한 동선은 재설계 대상이며 실제 작동 화면이나 검증된 분석 결과가 아닙니다.
- 세부 구현 조건과 자료 출처는 하단 ‘구현 메모’에서 확인할 수 있습니다.

## 조작

- 방향키 / Space / PageUp / PageDown: 이동.
- Home / End: 첫 장 / 마지막 장.
- 목차: 원하는 슬라이드로 이동.
- F 또는 전체 화면 버튼: 전체 화면 전환.
- 시안 클릭: 확대 창. 이미지 재클릭: 원본 크기 / 화면에 맞춤.
- Escape: 열린 창 닫기.
- 브라우저 인쇄: 슬라이드별 한 페이지 출력.
- 모바일에서는 한 장씩 세로로 읽을 수 있는 배치로 전환됩니다.

## 수정과 재생성

수정 대상은 `source/slides.html`입니다. 생성된 HTML을 직접 편집하면 다음 빌드에서 덮어써집니다.

저장소 루트에서:

```sh
python3 docs/presentation/source/build.py
```

기준 이미지는 `../design/references/`, 공식 배포 폰트와 라이선스는 `fonts/`에 보관합니다. 재생성에는 Python 표준 라이브러리만 필요합니다.

## 확인한 범위

- Chrome에서 파일 직접 열기 및 오프라인 로딩. 외부 네트워크 요청 0건.
- Pretendard Variable 1.3.9 / Source Serif 4 4.005 로딩 완료.
- 20장 전체를 1440×900, 1920×1080, 390×844에서 확인.
- 목차, 키보드, 이미지 확대, 닫기 후 포커스 복귀, 구현 메모, 전체 화면 확인.
- 인쇄 PDF 20페이지 확인.
- 시각 확인 자료와 검사 결과는 저장소의 `output/playwright/`에 보관합니다.

## 공개 계획 수정 사항

- 본제품은 로컬 우선 데스크톱 앱, 웹은 14일간의 샘플 및 제한된 직접 분석 체험판입니다.
- 임베딩 기반 RAG는 유지합니다. 앱에서는 사용자 기기, 웹 직접 체험에서는 운영 기기가 임베딩을 실행합니다.
- GPT 분석의 외부 전송과 로컬 저장을 구분합니다. 사용자 AI 연결 호환성은 앱·웹에서 각각 검증해야 합니다.
- 총예산 3만 원은 계획 상한입니다. 운영 기기·접속 방식·지원 OS·체험 분량·횟수·동시성·실제 비용은 미확정입니다.
- 공개 종료 후 유예·삭제 정책은 웹 체험 자료에만 적용하며 데스크톱의 로컬 작품은 유지됩니다.
- 본 문서 검증은 발표 자료의 표시·조작 검증입니다. 제품 배포, 실제 AI 연결, 비용 상한, 개인정보 삭제 검증의 완료를 뜻하지 않습니다.

## 데스크톱 시안 통합 · 2026-09-09

`story-guard.html`은 현재 30장입니다. 21장은 최신 결정·목차, 22–30장은 청록·아이보리 데스크톱 시안입니다. 하단 **새 앱 시안** 버튼으로 바로 이동합니다. 앞부분의 보라색·웹 분석 체험 구상은 이전 검토안으로 보존했습니다.

새 이미지 9장과 기존 이미지·폰트를 모두 HTML 내부에 내장했습니다. 팀원에게 **story-guard.html 파일 하나(약 26MB)**를 전달하면 인터넷이나 이미지 폴더 없이 열 수 있습니다. 이 로컬 경로 자체가 공개 URL은 아닙니다. 각 이미지는 클릭해 확대할 수 있습니다.
