추출 품질정답 사실·관계 중 찾은 비율 + 추출한 것 중 맞는 비율

명백한 모순, 예외가 있는 정상 사례, 별명·회상·소문, 미완결 떡밥을 포함합니다. 결과는 분자/분모와 함께 보고합니다.

E5의 384차원·512토큰·접두사·평균 풀링·정규화는 모델 카드 기준입니다. 청킹 320/480과 검색 6/12는 비교 실험 제안입니다. ONNX·양자화는 도입 전 호환성과 품질을 확인할 최적화 후보입니다.

Hermes의 Codex 연결은 참고 구현입니다. 임의의 OpenAI API 사용 권한이나 우리 제품의 공개 배포 가능성을 증명하지 않습니다. 실제 허용 경로와 사용 모델을 검증해야 합니다.

기본 구성은 로컬 임베딩 모델 1개 + 검색 코드 + 저장소이며, 외부 GPT가 추출·검토합니다. 검색 모델을 별도로 설치하지 않습니다. RAG는 검색 후 근거로 답하는 처리 방식, LangGraph는 단계 실행 도구, 관계 그래프는 결과 화면입니다. 재순위 모델은 선택 사항입니다.

기존 local_ai.py는 생성 모델과 임베딩 기본값을 공유하고 rag.py는 글자 수 기반 분할을 사용합니다. 제안 구조로 전환하려면 모델 역할 분리와 토큰 기준 분할부터 검증해야 합니다.

소규모 평가의 결과는 일반 사용자 전체에 대한 정확도 보장이 아닙니다. 인용 일치는 해석 정답 여부와 별도로 측정합니다.
