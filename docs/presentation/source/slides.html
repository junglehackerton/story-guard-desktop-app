현재 자료는 서비스 제안과 생성된 디자인 시안입니다. 기존 Tauri 로컬 앱을 바탕으로 데스크톱 본제품과 14일 웹 체험판을 분리하는 수정안입니다. 구독 연결, 설정집 분석, 전체 관계 편집, 공개 운영은 구현·실증 예정입니다. 시안은 실제 분석 결과나 작동 화면을 뜻하지 않습니다.

자료와 교정

  • 데스크톱 초기 검증 목표는 원고 10화·5만 자, 설정집·메모 별도 3개 문서·1만 자입니다. 웹 체험 분량과 횟수는 별도로 측정 후 결정합니다. 작가가 확정·구상을 구분합니다.
  • 수동 관계는 기본 구상으로 저장합니다. 기준 설정으로 지정한 관계는 ‘작가 지정’ 출처로 검토에 사용합니다.
  • 원본 자료, AI 분석, 작가 편집을 분리합니다. 같은 근거의 교정은 유지하고, 근거가 바뀌면 재확인하도록 합니다.
  • 전체 관계 편집은 추가·수정·제외·병합·분리·근거 연결·이력·실행 취소를 포함합니다. 원고 본문은 자동 수정하지 않습니다.

분석·작업·사용자 분리

  • 벡터·이름·관계 검색을 결합하고 근거를 확보한 뒤 검토합니다. 원문에 없는 인용을 임의 청크로 대체하지 않습니다.
  • 회차 순서, 작품 속 시간, 독자에게 밝혀진 시점을 구분합니다. 소문·거짓말·가정·미회수 떡밥은 확정 오류로 취급하지 않습니다.
  • LangGraph는 단계별 결과와 체크포인트를 보관합니다. 자료·모델·프롬프트·스키마·문맥·교정 버전으로 캐시를 구분합니다.
  • 기존 전체 동시 분석 2개 등의 가정은 확정값으로 사용하지 않습니다. 운영 기기에서 초기 임베딩·변경분 분석의 시간, 최대 메모리, GPT 호출량을 측정한 뒤 분량·동시성·대기열·재시도·전체 저장량을 제한합니다.
  • 웹 체험에는 서버 세션·보안 쿠키, 모든 자료 API의 소유권 검사, 인증 정보 암호화와 사용자별 갱신 직렬화가 필요합니다. 데스크톱은 OS 자격 증명 저장소와 로컬 API 접근 제한을 검증합니다. 사용자 구독 연결은 앱·웹 각각 별도 실증 대상입니다.
  • 구독 연결은 실제 분석·갱신·재연결을 실증해야 합니다. 호환되는 모든 구독이나 무제한 사용을 보장하지 않습니다.

모델 실행과 원고 전송

  • 청킹과 저장은 일반 코드, 의미 검색용 벡터 생성은 별도 임베딩 모델, 인물·관계 추출과 충돌 검토는 GPT가 담당합니다. 일반 GPT의 숫자 출력을 임베딩으로 사용하지 않습니다.
  • 데스크톱에서는 임베딩을 사용자 기기에서 실행합니다. 웹의 직접 분석 체험에서는 운영 기기에서 실행합니다. CPU 임베딩 모델 후보는 크기·라이선스·한국어 검색 품질·최소 사양을 확인한 뒤 확정합니다.
  • 원고의 로컬 저장은 외부 전송 없음과 다릅니다. 사용자 연결 GPT를 호출하면 분석에 필요한 원문·설정·추출 정보가 외부 제공자에 전송됩니다. 전송 범위·제공자·취소 방법을 실행 전에 안내합니다. 외부 제공자의 보관 정책은 별도이며 서비스가 일괄 삭제를 보장하지 않습니다.
  • 완전 오프라인 생성형 분석은 이번 구독 기반 분석 경로와 별도입니다. 현재 로컬 모델 코드가 있다는 이유만으로 품질·최소 사양 검증을 완료했다고 표시하지 않습니다.

평가와 운영

  • 정답 검수 인력이 부족하므로 ‘정밀도 90%’를 검증된 공개 조건으로 제시하지 않습니다. 자동 생성·자동 평가·수동 확인을 구분합니다.
  • 원문 위치, 기준·구상 분리, 교정 보존, 병합·분리·되돌리기, 사용자 격리, 중단 복구와 삭제를 필수 시나리오로 검증합니다.
  • 웹 체험은 확보한 운영 컴퓨터의 격리된 작업 환경과 HTTPS 공개 진입점을 후보로 둡니다. 개인 데스크톱 화면·로컬 관리 API를 직접 공개하지 않습니다. 총 운영 예산 상한은 3만 원이며 도메인·접속 서비스·트래픽·저장소·전력 등의 실제 비용과 초과 과금 차단 가능 여부를 확인해야 합니다. 자동 증설과 팀 유료 AI 계정 대체는 하지 않습니다.
  • 웹 체험은 14일 공개 후 7일간 조회·내보내기만 제공하고, 이후 웹 서버의 자료·벡터·분석·교정·작업·인증·백업을 삭제하는 계획입니다. 분석 종료와 함께 AI 연결은 더 이상 사용하지 않습니다. 사용자 직접 삭제 시점과 백업 삭제 방식을 공개 전에 확정·고지합니다. 이 정책은 데스크톱의 로컬 작품에는 적용되지 않습니다.

공개 전 결정 기록

  • 해커톤 규정: 설치형 제출 허용 여부, 공개 URL 유지 기간, 브라우저에서 요구되는 실제 기능, 투표 동선 확인.
  • 운영 담당: 주 담당자·대체 담당자, 접수 중지 권한, 장애 공지와 복구 순서, 공개·종료 시각 확정.
  • 배포: 지원 OS·서명 요구·설치 경고·모델 다운로드 용량과 실패 복구·업데이트 경로를 실제 배포 파일로 검증. 공개 사이트의 앱 다운로드 버튼은 검증된 파일이 준비된 뒤 연결.
  • 직접 분석: 사용자 연결의 실제 호출·갱신·만료·한도 소진과 웹 환경 호환성이 미검증이면 공개 보류. 팀 계정 대체 없이 사전 분석 샘플과 검증된 앱 범위만 안내하며 규정 충족 여부를 다시 확인.
