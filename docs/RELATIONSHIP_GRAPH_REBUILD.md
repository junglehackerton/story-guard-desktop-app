# 관계 탐색 화면 재구축 기준

## 폐기 범위

- 기존 `GraphView`의 전체 네트워크 캔버스 중심 구조
- 숨겨진 Cytoscape와 별도 SVG를 함께 사용하는 이중 렌더러
- 관계 수를 임의로 잘라서 화면에 그리는 방식
- 저장 좌표를 새 필터 화면에 재사용하는 방식

## 새 화면의 기본 단위

관계 그래프는 전체 원고를 한 번에 나열하는 화면이 아니라, 선택한 대상의 관계를 설명하는 탐색 화면이다.

1. 검색 또는 대상 목록에서 중심 대상을 선택한다.
2. 중심 대상과 직접 연결된 관계 그룹만 카드로 배치한다.
3. 같은 두 대상 사이의 여러 주장은 하나의 관계 카드로 묶는다.
4. 관계 카드에는 의미, 등장 회차, 상태, 근거 개수를 표시한다.
5. 카드를 열면 원문 근거와 작가 판단을 표시한다.
6. 2단계 이상 관계와 전체 구조는 별도 탐색으로 연다.

## 표시 모드

- `중심 탐색`: 중심 대상 + 1-hop 관계. 기본 모드.
- `문제 점검`: 충돌·중간 공백·끊긴 끝점·근거 부족만 목록과 강조선으로 표시.
- `회차 흐름`: 관계 그룹을 회차 축에 놓고 유지·변화·단절을 표시.
- `전체 구조`: 요약 카드와 연결 컴포넌트만 표시하며 모든 주장을 한 캔버스에 그리지 않는다.

## 상호작용 기준

- 중심 대상 선택 즉시 데이터 집계와 레이아웃을 다시 계산한다.
- 노드 선택과 관계 선택은 동일한 렌더러 이벤트를 사용한다.
- 드래그는 노드 이동, 빈 영역 드래그는 캔버스 이동으로 분리한다.
- 트랙패드 핀치는 캔버스 확대·축소로만 처리한다.
- 화면 맞춤은 현재 표시된 카드의 경계만 계산한다.
- 모든 관계와 근거는 목록에서 접근 가능해야 하며 캔버스 생략을 데이터 손실로 취급하지 않는다.

## 완료 조건

- 중심 대상 변경 후 한 번의 입력으로 화면 제목·카드·근거 패널이 함께 변경된다.
- 20개 이상의 대상에서도 카드가 겹치지 않고 읽을 수 있다.
- 100개 이상의 관계에서도 전체 화면이 축소판으로 변하지 않는다.
- 문제 상태를 누르면 실제 관계 카드와 원문 근거가 열린다.
- 원문 근거 문장은 저장된 원문과 일치하고 해당 문장이 강조된다.
- macOS와 웹 개발 서버에서 동일한 상호작용을 확인한다.
