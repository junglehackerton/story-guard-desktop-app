# Story Guard UI/UX 재점검

2026-09-14 macOS 데스크톱 앱에서 작품 목록, 원고·설정, 분석, 검토 결과, 관계 지도, 떡밥 후보, 앱 설정을 직접 이동하며 확인했다.

## 확인된 문제와 조치

1. 초기 로딩은 백엔드 준비 중 진행률이 18%에 오래 머물러 정지처럼 보인다. 실제 준비 완료까지 기다리면 진입하지만, 지연 상태 문구와 재시도 노출을 추가 검토한다.
2. 내 작품은 테스트 작품이 많아질수록 카드 목록이 길어진다. 작품 검색·보관·정렬이 다음 개선 대상이다.
3. 원고·설정은 회차 검색과 `원고 목록으로` 전환이 동작한다. 긴 원고는 목록과 본문이 함께 길어져 목록 독립 스크롤이 필요하다.
4. 분석 화면은 모델 설명과 분석 실행 정보가 한 패널에 과밀하다. 모델·추론 강도 선택은 분석 실행 시점에만 필요하고, 설정 화면에 반복되면 연결 상태 확인을 방해한다.
5. 검토 결과 후보 제목은 좁은 카드에서 여러 줄로 깨졌고, 근거 열이 길어질 때 가운데 빈 공간이 커졌다. 후보 제목을 최대 2줄로 제한하고 근거 열을 화면 높이 안에서 독립 스크롤하도록 수정했다.
6. 관계 지도는 카드가 적어도 컨테이너 최소 높이를 상속해 카드 아래 빈 스크롤이 생겼다. 탐색기와 관계 목록의 최소 높이를 해제했다.
7. 떡밥 후보 빈 상태는 안내 카드가 넓지만 메시지 자체는 이해 가능하다. 후보가 많아질 때 상태 필터를 추가한다.
8. 앱 설정은 연결·임베딩 상태를 확인하는 화면이므로 분석 실행용 모델 선택을 함께 보여주면 목적이 섞인다.

## 이번 보완 적용

- 작품 목록에 작품 제목 검색을 추가했다.
- 작품 목록에 최근 분석순·제목순·회차 많은 순 정렬을 추가했다.
- 작품 목록에 전체·재분석 필요·검토 대기·정리됨 상태 필터를 추가했다. 작품 수가 늘어도 작업이 필요한 작품만 빠르게 좁힐 수 있다.
- 초기 로딩이 8초 이상 지속되면 지연 안내를 표시한다.
- 진행률 갱신 때마다 지연 타이머가 초기화되던 문제를 제거해, 진행률이 움직이는 중에도 전체 로딩이 8초를 넘으면 안내가 표시되도록 했다.
- 분석 compact 패널의 간격을 줄였다.
- 그래프 셸의 고정 `100vw` 폭 계산을 제거해 창 너비에 따른 오른쪽 빈 공간·수평 오버플로를 줄였다.
- 문제 점검 결과가 0건일 때 그래프 캔버스 높이를 줄이고 빈 상태 안내를 표시한다.
- 작품 카드 제목을 최대 2줄로 고정해 카드 높이와 하단 액션의 정렬을 유지한다.
- 앱 설정의 ChatGPT 패널에서는 모델·추론 강도 선택을 숨기고 연결 상태·연결 해제만 제공한다. 모델 선택은 분석 화면과 초기 준비 화면에 유지한다.
- 앱 설정의 고급 로컬 생성 모델 섹션은 기본 접힘으로 바꿔, 일반 사용자가 연결·임베딩 상태를 먼저 확인하도록 한다.
- 관계 카드 목록은 기본 12개만 먼저 보여주고 `관계 n개 더 보기`로 전체 목록을 명시적으로 펼친다. 검색·모드·중심 대상이 바뀌면 다시 접혀 긴 목록이 화면을 점유하지 않는다.
- 검색·모드·중심 대상 변경 시 이전 관계 선택을 초기화해, 현재 화면에 없는 관계의 설명이 남지 않도록 한다.
- 사이드바의 현재 작품 선택 상자에 전체 작품명 툴팁과 접근성 이름을 제공해 긴 작품명도 확인할 수 있게 한다.
- 작품 목록에서 검색 중에는 제목을 `검색 결과`로 바꾸고 일치한 작품 수를 표시해 전체 작품 수와 검색 결과 수가 섞여 보이지 않게 한다.
- 중심 대상을 선택했을 때 그래프 헤더의 확인·점검 수를 전체 작품 수가 아니라 해당 대상의 직접 연결 수로 표시한다.
- 관계 탐색 방식 버튼에 탭 의미와 선택 상태(`role="tab"`, `aria-selected`)를 부여해 키보드·보조기기 사용자가 현재 모드를 알 수 있게 한다.
- 관계 탐색 캔버스의 고정 좌표(`400×210`)를 제거하고 실제 캔버스 크기와 창 크기에 맞춰 중심·방사형·회차 흐름 배치를 계산한다. 좁은 창에서 노드가 잘리거나 한쪽에 몰리는 문제를 줄인다.
- 관계 지도 중심 대상 선택 메뉴도 유형별 그룹과 이름순으로 통일해 긴 평면 목록에서 대상을 찾기 어렵던 문제를 줄인다.
- 관계 원문 근거는 기본 3개만 보여주고 나머지는 `근거 n개 더 보기`로 펼치도록 해, 근거가 많은 관계에서 긴 목록이 상세 패널을 밀어내지 않게 한다. 근거 내용과 원문 이동 기능은 그대로 유지한다.
- 검토 결과의 원문 근거 열도 기본 3개만 표시하고 같은 펼침 동작을 제공해, 후보 하나의 근거가 많을 때 다른 판단 UI가 아래로 밀리지 않게 한다.
- 전역 선택 상자를 서비스 색상·간격·화살표로 통일해 브라우저 기본 HTML 드롭다운처럼 보이던 입력 UI를 줄인다.
- 분석 화면에서 실제 작품 분석 동의와 샘플 연결 검증 동의가 동시에 보이던 중복 흐름을 제거했다. 샘플 연결 검증은 독립 연결 화면에서만 노출된다.
- 분석 기록이 길어질 때 진행 패널이 좁은 오른쪽 열에 갇혀 왼쪽에 큰 빈 공간이 생기던 문제를 수정했다. 기록이 있는 분석 화면은 모델 실행 패널과 진행 기록을 전체 너비의 두 열로 배치한다.
- 분석 화면을 최종적으로 한 열 흐름으로 정리해 분석 대상·동의·진행 기록 사이에 비어 있는 절반 열이 생기지 않도록 했다. 긴 기록은 페이지 스크롤로 자연스럽게 이어진다.
- 관계 지도 미리보기에서 위치를 계산한 노드 수보다 더 많은 선을 렌더링해 노드가 중앙의 기본 좌표에 겹치던 문제를 수정했다. 위치 계산과 캔버스 렌더링이 같은 관계 집합을 사용한다.
- 작품 화면 상단의 영문 `nodes / links` 배지를 `대상 n개 / 관계 n개`로 바꿔 본문 용어와 언어를 통일하고, 접근성 이름도 함께 제공한다.
- 분석 설정의 임베딩 모델과 관계 지도 회차 범위 선택 상자에 명시적 접근성 이름을 추가해 키보드·보조기기 사용 시 대상과 범위를 구분할 수 있게 했다.
- 관계 지도 미리보기 라벨을 말줄임표 대신 줄바꿈으로 표시하고 노드 기본 크기를 조금 키워, 긴 이름이 같은 접두사로 잘려 구분되지 않던 문제를 줄였다.
