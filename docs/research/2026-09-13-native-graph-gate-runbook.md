# 네이티브 관계 지도 최종 인수 절차

이 문서는 1~8 인수 중 관계 지도의 실제 Mac 입력만 확인하기 위한 절차다. 자동화 테스트가 통과했다는 사실과 실제 트랙패드 입력 확인을 섞지 않는다.

## 실행 조건

- 최신 번들: `src-tauri/target/release/bundle/macos/Story Guard.app`
- Mac 잠금 해제 상태
- 기존 검증 작품 또는 10편 이상 원고가 있는 작품 1개
- 창 크기를 바꿀 수 있는 데스크톱 환경

## 확인 순서

1. 최신 `Story Guard.app`을 한 번만 실행하고 기존 작품을 연다.
2. `관계 지도`에서 `전체 관계`를 선택한다. 노드와 선이 화면 안에 배치되고 근거 패널이 비어 있지 않은지 확인한다.
3. 트랙패드 핀치를 지도 중앙에서 두 번 수행한다. 하단 배율이 변하고 페이지 전체가 확대되지 않아야 한다.
4. 두 손가락으로 지도 영역을 수평·수직 이동한다. 노드가 함께 이동하고 브라우저/앱 외부 스크롤바가 생기지 않아야 한다.
5. `점검 필요`를 선택한다. 고립 후보와 끊긴 끝점만 표시되고, 문제 없는 노드는 숨겨지거나 비활성화되어야 한다.
6. 관계 선을 선택한다. 오른쪽 근거 패널에 관계 설명과 회차가 표시되고, 원문 열기 후 해당 문장이 강조되어야 한다.
7. 창을 760×720까지 줄였다가 다시 넓힌다. 지도와 근거 패널이 겹치지 않고 `화면에 맞춤`이 현재 창에 맞게 동작하는지 확인한다.
8. 창을 닫고 다시 실행한다. 작품·인증 상태가 유지되고 동일한 지도 상태로 진입하는지 확인한다.

## 판정 기록

각 단계에서 `통과` 또는 `실패`를 기록하고, 실패 시 창 크기·입력 동작·선택한 노드/관계·스크린샷 경로를 함께 남긴다. 이 절차가 끝나면 `native-gate-status-20260913.json`의 `native_status`를 `passed`로 갱신하고 증거 스크린샷 경로를 추가한다.
