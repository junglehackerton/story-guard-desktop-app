# 관계 그래프 제품 기준

관계 지도는 원고에 등장한 단어를 많이 보여주는 화면이 아니다. 작가가 **어떤 관계가 근거를 갖고 이어지는지, 어디에서 끊겼는지, 어떤 후보를 직접 확인해야 하는지**를 짧은 시간에 판단하는 검토 도구다.

## 반드시 완성할 것

1. **관계의 의미와 근거를 함께 표시한다.** 선에는 대표 술어와 후보 수만 표시하고, 선택하면 오른쪽 패널에서 모든 후보·회차·원문 chunk를 확인한다. AI 추출 후보와 작가가 확정한 설정은 상태와 문구를 분리한다.
2. **끊긴 관계를 숨기지 않는다.** 엔티티가 누락된 끝점은 `미확인 대상 #ID` 고스트 노드와 적갈색 점선으로 표시한다. 고스트는 저장 엔티티가 아니며, 목록과 근거 패널에서 원인과 근거 유무를 확인한다.
3. **관계 건강도를 현재 화면 범위와 일치시킨다.** 연결 컴포넌트, 고립 후보, 근거 부족, 미분류 관계, 충돌, 회차 변화, 중간 공백, 명시적 단절, 끝점 누락을 현재 회차·검색·유형 필터 기준으로 계산한다.
4. **전체 관계에서도 읽을 수 있게 배치한다.** 연결 컴포넌트는 균형 그리드로 나누고, 각 섬은 고차수 앵커에서 아래로 흐르는 계층형 배치를 사용한다. 동일한 대상 쌍의 병렬 후보는 대표선 하나로 집계하되 후보 정보는 삭제하지 않는다.
   각 섬에서 신뢰도·원문 근거·주장 수가 높은 연결을 자동으로 백본으로 선정해 굵게 표시한다. 백본은 읽기 순서를 돕는 시각적 힌트일 뿐이며 다른 후보를 숨기거나 확정하지 않는다.
5. **분리된 망을 직접 탐색한다.** 연결 컴포넌트가 둘 이상이면 `망 1 · N개 대상 · M개 관계` 선택기가 나타나고, 선택 시 해당 섬의 중심성이 가장 높은 대상을 기준으로 확대 검토한다. 고립 엔티티와 끝점 누락 관계는 섬 수에 섞지 않는다.
6. **문제에서 원문까지 한 번에 이동한다.** 건강도 경고, 끊긴 관계 목록, 선 선택, 오른쪽 근거 패널이 같은 관계 ID를 공유해야 한다. 어떤 진입점으로 들어가도 해당 후보와 원문 근거가 선택되어야 한다.
7. **명시되지 않은 중간 공백도 후보로 표시한다.** 같은 관계의 근거가 비연속 회차로만 나타나면 자동으로 `중간 공백 후보`로 표시하되, 사실 단절로 확정하지 않고 해당 회차 근거를 작가가 확인하게 한다.
8. **깊은 관계망은 화면 비율을 지킨다.** 9단계보다 깊은 연쇄는 6개 레벨 단위로 접어 2차원에 배치하고, 일반 허브·분기망은 계층 구조를 유지한다. 배치가 안정적이어도 읽을 수 없는 축소라면 실패로 판정한다.
9. **문제 관계만 강조하는 진단 모드를 제공한다.** 전체 데이터와 건강도 수치는 유지한 채 정상 연결의 시각적 대비를 낮춰 충돌·공백·단절·근거 부족·끝점 누락을 먼저 찾을 수 있어야 한다.
10. **관계 의미의 반대 방향을 보수적으로 감지한다.** `동행/협력`처럼 고정된 분류에만 의존하지 않고 `계약 체결 ↔ 계약 거절`, `보호함 ↔ 적대/의심` 같은 구체적 술어도 같은 대상 쌍에서 함께 나타나면 충돌 후보로 표시한다. 시간 순서나 예외 규칙은 근거 패널에서 작가가 판단한다.

## 줄이거나 제거할 것

- 모든 후보에 긴 라벨을 그려 캔버스를 헤어볼로 만드는 동작
- 관계 의미가 없는 `관계`, `관련`, `동시 등장`을 확정된 선처럼 강조하는 표현
- 현재 범위 밖의 회차 이슈를 현재 화면의 선 색상에 섞는 동작
- 누락된 끝점을 빈 공간에 버리거나, 반대로 임의 엔티티로 추정해 연결하는 동작
- 그래프 안에서 원고를 편집하는 복잡한 기능. 원고·설정 화면에서 편집하고 지도에서는 검토와 이동에 집중한다.
- 자동 배치가 실행될 때마다 달라지는 물리 시뮬레이션. 같은 데이터와 필터에서는 같은 배치를 유지해야 한다.

## 검토 기준

### 구조

- `전체 관계`를 눌러도 화면이 가로 한 줄로 축소되지 않는다.
- 연결 컴포넌트가 둘 이상이면 건강도에서 즉시 보이고, 각 섬의 선과 노드가 겹치지 않는다.
- 고립 후보와 끝점 누락 후보가 일반 관계와 다른 경로로 접근 가능하다.
- 선을 하나로 집계해도 오른쪽 후보 목록에서 개별 방향·회차·근거를 잃지 않는다.

### 해석

- 모든 관계 설명은 출발 대상, 도착 대상, 술어, 근거 수를 명시한다.
- `AI 추출 후보`, `근거 부족`, `확인 필요`, `작가 확정`의 상태가 색상·문구·아이콘으로 구분된다.
- 같은 대상 쌍의 반대 방향 후보와 충돌 후보를 숨기지 않는다.
- 필터·회차 변경 후 건강도 수치와 선 상태가 동일한 범위를 가리킨다.

### 성능·접근성

- 일반 장면은 자동 맞춤 뒤에도 읽을 수 있는 최소 배율을 유지한다.
- 복잡한 지도는 대표 라벨 수를 제한하고, 전체 후보는 근거 패널에서 확인한다.
- 캔버스가 실패하면 원인과 다시 시도 버튼을 표시하며, 빈 캔버스만 남기지 않는다.
- 관계 건강도와 누락 목록은 `role=status`, 명확한 버튼 이름, 키보드 포커스로 접근할 수 있어야 한다.

## 이번 구현의 판정 범위

현재 저장소는 위 구조와 UI 계약을 코드·Vitest·브라우저 스모크로 확인한다. 장편 원고의 실제 추출 정확도와 Windows 네이티브 실행, 사용자 GPT 실호출은 별도 환경 증거가 필요하며 목업 결과로 통과 처리하지 않는다.
